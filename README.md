# Ochestrator

A lightweight orchestrator that provides automation for deploying, scaling, and otherwise managing docker containers.

## ⚙️ Installation

1. *Clone the repo:*

```bash
git clone https://github.com/sulaimonshittu/ochestrator.git
```

2. *Install dependencies:*

```bash
go mod tidy
```

## Components

- TASK
- MANAGER
- WORKER
